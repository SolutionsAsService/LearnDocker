Chapter 3

Compose

Real applications are several containers. Compose describes them in one file and starts, stops and removes them together.

The file

Make a folder named demo containing the hello-node app from the last chapter in a folder called hello-node, and this file next to it.

  • web is built from the Dockerfile in ./hello-node and publishes port 3000. Its healthcheck runs a command inside the container every two seconds and marks it healthy when the command succeeds.
  • probe is an alpine container that fetches a page from http://web:3000, then exits.
  • depends_on with condition: service_healthy makes probe wait until web is healthy. A plain depends_on only controls the order of starting, not whether the first service is ready.

Start it

The command is docker compose, with a space.

probe printed a page from web without being given an address. Compose put both services on a network it created, and on that network a service's name is its address. The next chapter shows why that works.
