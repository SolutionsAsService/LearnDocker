What is checked, and how

  • Commands. Every command on the site is in data/lessons.json. node scripts/check.mjs runs them against a real Docker daemon, in a fresh folder, and fails if one exits with an error or does not print what the lesson says it prints. node scripts/check.mjs --update rewrites the output shown on the pages from that run.
  • Measurements. The reuse figures on the home page and the table on the Images page come from real builds: the script builds the app, changes one thing, builds again and records which steps the build marked as cached. The layer sizes come from docker history. The gate fails if the measurements stop supporting the lesson's claim (for example, that editing server.js leaves npm install reused).
  • Links. The script fails on any internal link that points nowhere, on any external font or script, and on a short list of phrases the first review of this site turned up.
  • Claims. A statement about how Docker behaves is either something the page shows being run, or it says so ("we did not run that form here"). Times vary by machine, and image sizes depend on the base image version.

What is not covered

Kubernetes, Docker Desktop, Windows containers, image security scanning, multi-stage builds, build secrets, registries other than Docker Hub, and a swarm of more than one machine. Pulling images and installing packages inside a build need network access, which the check machine had only for pulling images; that is why the lab app has no dependencies to install.

What changed from the first version

The first version had seven links to pages that did not exist, a news list with no sources, and a promise of labs that did not exist. Its Dockerfile lesson built an image whose container exited at once because the app it named was never provided. Its Compose lesson used the docker-compose command, which a current Docker install does not have. Its sample app claimed its database service would be waited for, when the setting it used only orders start-up. Those were measured by running them. The lessons were rewritten, the sample app was replaced by the dependency-free lab app, and the news list was removed.
